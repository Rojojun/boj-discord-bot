# 봇 공통 조건

- Rust로 작성하는 Discord 봇. 사용자 3명 규모. 모든 기능에 화면 디자인 단계 생략.
- DB 없이 Discord 사용자 ID별 디렉터리에 설정과 진행 상태를 JSON 키/값 파일로 저장한다. solved.ac 핸들은 설정값이다. 재시작 후 설정과 진행 상태를 복구한다.
- 봇 프로세스의 최대 RSS 목표는 100 MiB. 사용자 3명이 사용하는 상황을 기준으로 측정한다.
- solved.ac 공식 v4를 기준으로 연동한다. v3는 지원 종료됐다. BOJ 연동 종료 이후 실제 제출은 solved.ac 연동 저지(예: DOJ)를 전제로 검토한다.
- v4 조회 범위와 인증 조건은 미확인이다. 실계정 연동 검증과 외부 응답을 대체한 자동 테스트를 각각 기록한다.
