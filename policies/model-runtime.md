# 백준봇 런타임 모델 실행

- 요구사항에서 사용자 의도나 문맥을 해석하거나 추천 후보의 적합성을 판단해야 하는 기능은 봇 호스트에 설치된 Google Antigravity CLI(`agy`)를 호출한다. 실행 파일 경로와 모델 ID를 봇 설정으로 지정할 수 있게 한다.
- 지원 트랙 매칭, 문제를 풀기 위한 선수 개념 판단, 조건을 충족한 선수·대체 문제의 적합도 판단을 모델에 맡긴다. 모델 응답은 입력과 후보에 근거한 제안으로 취급한다. 정해진 커리큘럼 진행 기준, 티어 및 문제 수 제한, 해결 기록 확인, 알림 시각과 스킵 기간은 Rust가 적용한다.
- 요청에는 목표 문장 또는 문제 제목과 태그, 선택 가능한 내부 후보만 전달한다. Discord ID, solved.ac 핸들, 채팅 전체, 비밀 값은 전달하지 않는다.
- 별도 작업 디렉터리에서 비대화식으로 호출하고, 샌드박스와 도구 접근 제한이 실제로 작동하는지 검증한다. 명령행은 셸을 거치지 않고 구성한다. 동시 호출은 한 건으로 제한하고 호출 시간 제한을 둔다.
- 구조화 응답의 형식과 후보 ID를 Rust에서 검증한다. 모델은 과제나 설정을 직접 변경하지 않는다.
- 호출 실패 시 기존 트랙 목록이나 문제 태그 기반 도움을 제공한다. 호스트에서 CLI의 로그인 및 실제 모델 호출을 확인하고, 봇과 CLI가 함께 실행될 때의 메모리 사용량을 별도로 측정한다.
